# Employee Dashboard using Power BI

This project is a simple dashboard created using Microsoft Power BI.

The goal of this project is to visualize and analyze employee data.

## Tools Used
- Microsoft Power BI
- Power Query

## Dashboard Overview
The dashboard shows:
- Total number of employees
- Average salary
- Average and maximum age
- Male and female employee distribution
- Salary information
- Employee distribution by country
- Total amount by year

## Key Results
- Total Employees: 1,019
- Female Employees: 534 (52%)
- Male Employees: 485 (48%)
- Average Age: 59

## Source: Kaggle
## About
This project was created to practice data visualization and reporting skills using Power BI.
